Click any bit to flip: (Bits 0..39: 40-bit Header | Rest: per-block k & rank payloads)
Header Protection Analysis: The 40-bit header encodes the original bit-length and block size $n$. If a payload bit flips within a valid range, the codec decodes with distorted syllables; if it flips the rank outside $[0, C(n,k)-1]$, an explicit combinadic boundary error is thrown. The header has no CRC or parity — proving why real transmission channels layer Reed-Solomon or cyclic redundancy checks over combinadic streams.

Final Evaluation Results

Does it compress or merely encode?

Plain-language scientific verdict: Yukti is an exact (k, rank) combinadic block codec. It truly compresses when data entropy is skewed (sparse 5% ones save up to 45% bits, dense 95% save 46%, runs of zeros compress 50%). It merely encodes (expands) balanced text like "saket" and uniform white noise ($H(p) \approx 1.0$), because balanced groups have maximal $C(n, k)$ cardinality requiring full rank bits plus the 40-bit header.
